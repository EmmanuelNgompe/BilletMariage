# 💍 Billet de Mariage de David

Une application web élégante et interactive créée pour célébrer un mariage à travers une expérience numérique unique.
Ce projet combine design romantique, animations douces et une présentation harmonieuse des moments forts du couple.

---

## 🌸 Aperçu

L’application affiche :
- Un **compte à rebours** dynamique jusqu’au jour du mariage.
- Une **galerie photo** en mosaïque avec effets de survol.
- Une **histoire du couple** en plusieurs parties, illustrée et animée.
- Une section **musique** pour accompagner la lecture.
- Des éléments visuels raffinés (fonds, typographies, couleurs pastel).

---

## 🧩 Technologies utilisées

- **React.js** – pour la structure et les composants interactifs.
- **CSS3** – pour les animations, effets hover et mise en page responsive.
- **JavaScript (ES6)** – pour la logique du compte à rebours et les interactions.
- **HTML5** – pour la structure sémantique.

---

## 🚀 Installation et exécution

1. Clone le dépôt :
   `ash
   git clone https://github.com/EmmanuelNgompe/BilletMariage.git
   cd BilletMariage
   npm install
   npm install react-router-dom@latest
   npm start
   `

L’application sera disponible sur http://localhost:3000.

---

## 💡 Personnalisation

- Remplace les images dans src/images/ et images2 par tes propres photos.
- Modifie les textes dans Billet.jsx pour adapter l’histoire du couple puis les images.
- Ajuste les couleurs et polices dans App.css pour correspondre au thème du mariage.
